# Tiny Being MVP 开发路线

## 当前目标：V0.1 最小可玩版本

验证玩家离开一段时间再回来后，能发现 Tiny Being 的变化，并愿意照顾它。

### 已纳入

- 一个幼体、一个固定房间
- 饱食、心情、清洁、精力
- 喂食、玩耍、清洁、睡觉与抚摸
- 本地存档和 24 小时离线结算上限
- 明确的动作、表情、状态和关系反馈

### 完成标准

- 首次打开能在一分钟内完成孵化并理解操作
- 关闭再打开不会丢失进度
- 修改存档时间后，四项状态按规则变化
- 手机和桌面浏览器均可完成全部操作
- 低状态能被动作和提示直接识别

## V0.2：完整基础养成

- 蛋、幼体、成长期、成年体四个阶段
- 健康、生病、治疗和昏睡恢复
- 普通食物与零食选择
- 接球小游戏与可清除污渍
- 成长记录和基础音效
- 三种隐藏性格倾向影响待机行为

## V0.3：陪伴感增强

- 更多待机与重逢反馈
- 照顾历史摘要
- 通知策略与状态节奏调优
- 可安装 PWA 与基础无障碍完善

## V1.0：基础版验收

- 进行至少 3 天的小规模试玩
- 评估需求识别、反馈清晰度和回访意愿
- 根据数据调整衰减速度和操作收益
- 暂不加入克苏鲁、战斗、探索、货币与服务端

## 后续主题演进

基础循环成立后，再从轻微异常逐渐进入克苏鲁主题：奇怪梦话、物品位移、异常成长记录、不可解释的形态、梦境与观察关系反转。异常内容不应掩盖“照顾一个生命”这一核心。
